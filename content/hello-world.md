## 先让程序跑起来

学习一门语言时，第一个目标很简单：让计算机输出一句话。新建一个 `.cpp` 文件，保存下面的代码。

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

在 Dev-C++ 中，可以通过“运行”菜单中的“编译并运行”完成这一步。先保存文件，再执行编译。

## 这几行代码做了什么

- `#include <iostream>` 引入标准输入输出库。
- `main()` 是程序开始执行的入口。
- `std::cout` 将文本输出到控制台。
- `std::endl` 输出换行并刷新输出流。
- `return 0` 表示程序正常结束。

代码写在源文件里，编译器把它转换成可执行程序，运行程序后才会看到输出。
